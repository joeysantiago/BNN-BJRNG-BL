# Dropdown & Compact Field Size Standard

**Not applicable to Thakurg.** The site does not use PrimeNG (`p-select` / `p-multiselect`) or a generic entity-form grid, so there is no dropdown-size standard to follow. Native `<select>` and `<input>` controls follow the shared styles in `src/styles.scss`.

If a component library with dropdowns is introduced later, replace this file with the size rule for it.
