# Bank and payment app logos

The logos Tracker shows next to transactions, cards and loans (`app-tracker-bank`). Each file was downloaded once from Wikimedia Commons, checked to be a plain image (no scripts, event handlers or external links), stripped of editor metadata and cropped to the brand's symbol with its `viewBox`. The file name is the bank's main SMS sender code in lower case (`TRACKER_BANKS` in `src/app/core/tracker-meta.ts`).

The logos are trademarks of their owners and are used only to name the bank. Banks without a file here show a badge with their short name on their brand colour.
