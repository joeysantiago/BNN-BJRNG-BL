# Audio folder for /creta

Copy your audio files (mp3, m4a, aac, ogg, opus, wav, flac) into this folder and run `npm run build`.
The playlist is created automatically from the files, in file name order. There is nothing to edit.

- The title comes from the file name (`01 - My_Song 320 Kbps.mp3` shows as "My Song").
- For a cover picture, add an image with the same name (`my-song.mp3` and `my-song.jpg`).
- `playlist.json` is rewritten on every build, so do not edit it.
